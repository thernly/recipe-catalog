## Simple Implementation Notes

- **Database vs. Redis:** Use database for state storage to avoid adding Redis dependency
- **Email Service:** Start with console logging, add real email service later
- **CSRF:** Use existing library, don't build from scratch
- **Sanitization:** Strip HTML entirely (plain text only) rather than complex whitelist
- **Tests:** Focus on integration tests for critical paths, not 100% unit test coverage
- **Logging:** Simple hash function, don't overcomplicate
- **Indexes:** Add conservatively based on actual query patterns
- **Refactoring:** Only refactor when actively working on a file
